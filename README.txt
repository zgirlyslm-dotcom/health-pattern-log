HEALTH PATTERN LOG v2

This version includes Today / Meds / Trends / Doctor pages; 1–10 tap scales; meal, sleep, water, activity and weight logging; timestamped medication doses; treatment-change tracking; trends; physician report; and JSON/CSV backup.

IMPORTANT ABOUT OPENING IT LIKE AN APP:
Android will open a loose local HTML file in Chrome. That is normal and cannot be changed by the ZIP itself.
For the standalone, no-address-bar app experience, these files are now PWA-ready (manifest + icons + offline service worker). They must first be served from a secure web address (HTTPS), then Chrome can use “Add to Home screen” / “Install app.” Once installed, it launches in its own standalone window and can work offline.

DATA:
Your entries are stored locally in the browser/app storage on the device. Export a JSON backup regularly. Clearing browser/app site data can erase locally stored entries.
